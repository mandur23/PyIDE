# 영상 편집 앱 기능 설계 (검토용 초안)

[video-editor-plan.md](video-editor-plan.md)의 3절 "첫 버전 기능"을 전문 편집 앱 수준으로 자세히 늘린 문서입니다. 어도비 프리미어 같은 앱에서 편집자가 매일 쓰는 기능을 기준으로 잡았습니다. 이름, 아이콘, 화면 모양은 우리 것으로 만들고, 단축키만 업계에서 흔히 쓰는 배치를 따릅니다. 그래야 다른 편집 앱을 쓰던 사람이 바로 씁니다.

기능이 많아서 세 묶음으로 나눕니다. 각 기능 앞의 표시가 묶음입니다.

| 표시 | 묶음 | 뜻 |
| --- | --- | --- |
| **[1]** | 첫 출시 | 유튜브·쇼츠 영상을 처음부터 끝까지 만들 수 있는 최소 기능 |
| **[2]** | 프로 편집 | 편집을 업으로 하는 사람이 빠르게 일하는 데 필요한 기능 |
| **[3]** | 고급 | 시간이 많이 들거나 연구가 필요한 기능 |

## 1. 화면과 작업 공간

**패널.** 화면은 패널로 나뉩니다. 패널은 끌어서 옮기고, 탭으로 겹치고, 떼어서 따로 띄울 수 있습니다 [2]. 첫 출시는 고정된 배치 몇 개만 둡니다 [1].

| 패널 | 하는 일 | 묶음 |
| --- | --- | --- |
| 프로젝트 | 가져온 미디어, 폴더(빈), 시퀀스 목록 | [1] |
| 소스 모니터 | 원본 클립을 보고 In/Out을 정함 | [1] |
| 프로그램 모니터 | 시퀀스 결과를 봄 | [1] |
| 타임라인 | 시퀀스 편집. 여러 시퀀스를 탭으로 엶 | [1] |
| 효과 컨트롤 | 고른 클립의 속성, 효과, 키프레임 | [1] |
| 효과 | 비디오·오디오 효과와 전환 목록, 검색, 즐겨찾기 | [1] |
| 색 | 기본 보정, 커브, 색 휠, LUT | [1] 기본, [2] 나머지 |
| 스코프 | 파형, 벡터스코프, 히스토그램, RGB 퍼레이드 | [2] |
| 텍스트 | 텍스트와 도형 레이어, 스타일 | [1] |
| 오디오 믹서 | 트랙별 볼륨, 팬, 음소거, 솔로, 미터 | [2] |
| 소리 정리 | 대화·음악·효과 지정, 음량 맞추기, 덕킹 | [2] |
| 자막 | 자막 목록 편집, 스타일 | [1] |
| 마커 | 마커 목록, 이동, 내보내기 | [2] |
| 기록 | 편집 기록 목록, 원하는 지점으로 되돌리기 | [2] |
| 내보내기 대기열 | 여러 내보내기를 줄 세워 뒤에서 처리 | [2] |
| 메타데이터 | 파일 정보(코덱, 프레임 수, 색 공간, 타임코드) | [2] |

**작업 공간.** 일에 맞춘 패널 배치를 미리 둡니다. 위쪽 탭으로 바꿉니다.
- 편집 [1]: 프로젝트, 소스, 프로그램, 타임라인, 효과 컨트롤
- 색 [1]: 프로그램 모니터를 크게, 색 패널, 스코프 [2]
- 소리 [2]: 오디오 믹서, 소리 정리, 파형을 크게
- 자막과 그래픽 [1]: 자막 패널, 텍스트 패널
- 내보내기 [1]: 내보내기 설정과 대기열
- 사용자가 배치를 바꾸면 그 작업 공간에 저장하고, "원래대로"로 되돌립니다 [2]. 새 작업 공간을 이름 붙여 저장합니다 [2].

**모니터 공통.** 화면에 맞춤, 25~400% 확대, 안전 영역 표시(액션 93%, 타이틀 90%) [1], 격자와 가이드 [2], 투명 배경을 체커보드로 보기 [2], 전체 화면 재생(`Ctrl+\``) [1].

## 2. 프로젝트와 미디어 관리

**가져오기 [1].**
- 파일, 폴더째, 끌어다 놓기로 가져옵니다. 폴더를 가져오면 폴더 구조를 빈으로 만듭니다.
- 가져올 때 원본을 복사하지 않습니다. 경로만 기억합니다.
- 가져오는 동안 썸네일, 파형, 키프레임 위치 목록을 뒤에서 만듭니다. 진행은 상태 표시줄에 보입니다.
- 열 수 없는 파일은 이유와 함께 목록으로 알립니다(코덱 없음, 손상, HDR 미지원).
- 이미지 시퀀스(`img_0001.png`부터 번호가 이어지는 파일)를 영상 하나로 가져옵니다 [2].

**프로젝트 패널 [1].**
- 목록 보기(이름, 길이, 해상도, 프레임 수, 코덱, 사용 횟수, 라벨 색)와 썸네일 보기를 둡니다.
- 빈을 만들고, 이름을 바꾸고, 끌어서 정리합니다. 이름과 메타데이터로 검색합니다.
- 썸네일 위를 마우스로 훑으면 그 위치가 보입니다(훑어보기) [1].
- 라벨 색 8개를 둡니다. 클립의 라벨 색은 타임라인 클립 색이 됩니다 [2].
- "사용 안 한 미디어 고르기", "프로젝트에서 지우기(파일은 남김)"가 있습니다 [2].

**미디어 다시 연결 [1].** 원본 파일을 옮기거나 이름을 바꾸면 클립이 "오프라인"이 됩니다. 프로젝트를 열 때 오프라인 목록을 보여 주고, 폴더 하나를 고르면 같은 이름과 길이의 파일을 찾아 한꺼번에 다시 연결합니다. 오프라인 클립은 빨간 화면에 "미디어 없음"으로 그려지고, 내보내기 전에 경고합니다.

**클립 해석 [2].** 원본의 프레임 수를 다르게 해석합니다(예: 60fps 영상을 30fps로 해석하면 느린 화면). 픽셀 비율, 알파 채널 무시, 필드 순서를 바꿀 수 있습니다.

**서브클립 [2].** 소스 모니터에서 In/Out을 정하고 "서브클립 만들기"를 하면 그 구간만 가리키는 새 항목이 프로젝트에 생깁니다. 긴 녹화본을 정리할 때 씁니다.

**동기화 [3].** 카메라 영상과 따로 녹음한 소리를 파형으로 맞춰 하나의 클립으로 묶습니다.

**프로젝트 파일 [1].** `.ncut` 하나(JSON)입니다. 프로젝트 저장 위치 옆에 `<이름>.ncut-cache` 폴더를 두지 않고, 캐시는 앱 공통 캐시에 둡니다(프로젝트 파일을 옮겨도 깨지지 않음). "프로젝트 모아 담기" [2]는 프로젝트와 쓰인 미디어(쓰인 구간만 자르는 선택 포함)를 한 폴더로 복사합니다.

## 3. 시퀀스

- **설정 [1]:** 해상도, 프레임 수(23.976, 24, 25, 29.97, 30, 50, 59.94, 60), 소리 표본율(48kHz), 화면 비율, 배경색. 미리 정한 것: 유튜브 1080p30, 4K30, 쇼츠 1080x1920, 정사각 1080x1080.
- **클립에서 만들기 [1]:** 첫 클립을 끌어다 빈 타임라인에 놓으면 그 클립에 맞는 설정으로 시퀀스를 만듭니다. 이미 클립이 있는 시퀀스에 설정이 다른 클립을 넣으면 "시퀀스를 클립에 맞출까요?"를 한 번 묻습니다.
- **여러 시퀀스 [1]:** 프로젝트에 시퀀스를 여러 개 두고 타임라인 탭으로 엽니다.
- **중첩 [2]:** 고른 클립들을 묶어 새 시퀀스로 만들고, 그 자리에 시퀀스 하나를 클립처럼 둡니다(두 번 누르면 들어감). 시퀀스를 다른 시퀀스에 끌어다 넣을 수도 있습니다. 순환 참조는 막습니다.
- **시퀀스 복제 [1]:** 버전을 나눠 실험할 때 씁니다.
- **크기 다른 클립 [1]:** 시퀀스와 해상도가 다른 클립은 기본으로 "프레임에 맞춤"합니다. 설정에서 "원래 크기" 또는 "채우기"를 고릅니다.
- **자동 리프레임 [3]:** 16:9 시퀀스를 9:16으로 복제하면서 클립마다 위치 키프레임을 만들어 주인공을 화면 안에 둡니다(움직임 추적이 필요해서 3차).

## 4. 소스 모니터와 프로그램 모니터

**재생 [1].**
- `Space` 재생·멈춤, `J`/`K`/`L` 뒤로·멈춤·앞으로(여러 번 누르면 2배, 4배, 8배), `K`를 누른 채 `J`/`L`은 한 프레임씩 천천히.
- `←`/`→` 한 프레임, `Shift+←`/`→` 다섯 프레임, `Home`/`End` 처음·끝, `↑`/`↓` 이전·다음 편집점.
- 타임코드를 눌러 숫자로 이동합니다(`+30`은 30프레임 뒤로 등 상대 이동).
- 반복 재생, In부터 Out까지 재생.

**In/Out과 삽입 [1].**
- `I` In, `O` Out, `X` 클립 전체를 In/Out으로, `Alt+X` 지우기.
- 소스 모니터에서 영상만, 소리만 끌어 오는 손잡이를 둡니다.
- `,` 삽입: 재생 위치에 넣고 뒤를 민다. `.` 덮어쓰기: 재생 위치부터 덮는다.
- **3점 편집:** 소스 In/Out과 시퀀스 In(또는 재생 위치)으로 넣습니다. **4점 편집 [2]:** 길이가 다르면 "속도 맞춤, 소스 Out 무시, 시퀀스 Out 무시" 중에서 묻습니다.
- 들어갈 트랙은 타임라인 왼쪽의 소스 패치(V1, A1 표시)가 정합니다(5절).
- 프로그램 모니터에서 `;` 들어올리기(빈자리 남김), `'` 뽑아내기(빈자리 메움) [2].

**프로그램 모니터 추가 [1].**
- 고른 클립의 위치·크기·회전을 화면에서 직접 끌어 바꾸는 손잡이를 둡니다.
- 마스크와 텍스트도 화면에서 바로 고칩니다.
- 비교 보기 [2]: 지금 프레임과 참고 프레임을 나란히 또는 반으로 갈라 봅니다. 색을 맞출 때 씁니다.
- 트리밍할 때는 편집점 앞뒤 프레임을 두 칸으로 보여 줍니다 [1].

## 5. 타임라인과 트랙

**트랙 [1].**
- 영상 트랙(V1, V2, …)은 위가 앞에 그려집니다. 오디오 트랙(A1, A2, …)은 모두 섞입니다. 자막 트랙은 따로 있습니다(13절).
- 트랙 추가·삭제·이름 바꾸기, 높이 조절, 모든 트랙 높이 맞추기.
- 트랙마다 켜기·끄기(눈, 스피커), 잠그기, 솔로(오디오).
- **소스 패치:** 소스 클립이 어느 트랙으로 들어갈지 정합니다. **대상 트랙:** 이동, 붙여넣기, 편집점 이동이 어느 트랙에 적용될지 정합니다. 둘은 다른 표시입니다.
- **동기 잠금 [2]:** 삽입이나 리플 삭제로 시간이 밀릴 때 동기 잠금된 트랙도 같이 밀립니다. 이게 없으면 다른 트랙의 소리와 자막이 어긋납니다.
- 오디오 트랙 종류: 모노, 스테레오 [1], 5.1 [3].

**클립 [1].**
- 영상과 그 영상의 소리는 "연결"되어 같이 움직이고 같이 잘립니다. `Ctrl+L` 연결 끊기·잇기. `Alt`를 누르고 누르면 한쪽만 고릅니다.
- 그룹 [2]: 여러 클립을 묶어 같이 옮깁니다(연결과 다름, 길이는 각자).
- 클립 켜기·끄기(`Shift+E`), 이름 바꾸기, 라벨 색.
- 클립이 다른 클립과 어긋나면(연결된 영상과 소리가 서로 밀리면) 어긋난 프레임 수를 빨간 숫자로 보여 줍니다. 오른쪽 버튼으로 "다시 맞추기"를 합니다 [2].
- 클립 끝에 원본이 더 남았는지(핸들) 모서리 표시로 보여 줍니다. 전환을 넣을 때 중요합니다.

**놓기와 이동 [1].**
- 끌어다 놓으면 기본은 덮어쓰기입니다. `Ctrl`을 누르고 놓으면 삽입합니다. 놓을 곳에 미리 그림자를 보여 줍니다.
- 붙기(`S`): 클립 끝, 재생 위치, 마커, In/Out에 붙습니다. 붙을 때 세로 선을 보여 줍니다.
- 고른 클립을 키보드로 한 프레임씩 옮기기(`Alt+←`/`→`) [2].
- 복사·붙여넣기는 대상 트랙의 재생 위치에 붙입니다. `Ctrl+Shift+V` 삽입 붙여넣기 [2]. **속성 붙여넣기** [2]: 다른 클립의 효과, 색, 위치, 속도 중 고른 것만 붙입니다.
- 클립 바꾸기 [2]: 프로젝트의 클립을 `Alt`를 누르고 타임라인 클립 위에 놓으면 길이와 효과를 유지한 채 원본만 바꿉니다.

**빈자리 [1].** 빈자리를 누르고 `Delete`로 메웁니다. "다음 빈자리로" 이동 [2]. 모든 트랙에서 빈자리 지우기 [2].

**확대 [1].** `=`/`-`, `\` 전체 맞춤, `Alt+휠`. 확대해도 재생 위치가 화면 안에 남습니다. 썸네일 띠는 확대 정도에 맞춰 촘촘해집니다.

**장면 나누기 감지 [3].** 이미 편집된 영상 하나를 가져오면 장면이 바뀌는 곳을 찾아 클립을 자동으로 나눕니다.

## 6. 편집 도구와 트리밍

| 도구 | 키 | 하는 일 | 묶음 |
| --- | --- | --- | --- |
| 선택 | `V` | 고르기, 옮기기, 끝 끌어 자르기 | [1] |
| 앞으로 트랙 선택 | `A` | 누른 곳부터 오른쪽 모든 클립 고르기. `Shift+A`는 뒤로 | [1] |
| 리플 편집 | `B` | 끝을 끌면 뒤 클립들이 따라 밀림. 빈자리가 안 생김 | [1] |
| 롤 편집 | `N` | 맞닿은 두 클립의 경계만 옮김. 전체 길이는 그대로 | [1] |
| 속도 늘이기 | `R` | 끝을 끌면 길이에 맞춰 속도가 바뀜 | [2] |
| 자르기(면도칼) | `C` | 누른 곳에서 나눔. `Shift`를 누르면 모든 트랙 | [1] |
| 슬립 | `Y` | 클립 위치와 길이는 두고 안의 원본 구간만 밀기 | [2] |
| 슬라이드 | `U` | 클립 내용은 두고 앞뒤 클립을 줄이며 옮기기 | [2] |
| 펜 | `P` | 키프레임 찍기, 고무줄 볼륨 | [2] |
| 손 | `H` | 타임라인 끌어 보기 | [1] |
| 확대 | `Z` | 누른 곳 확대 | [1] |
| 텍스트 | `T` | 프로그램 모니터에 텍스트 넣기 | [1] |

**키보드 편집 [1].**
- `Ctrl+K` 재생 위치에서 나누기(대상 트랙), `Ctrl+Shift+K` 모든 트랙.
- `Q` 재생 위치까지 앞부분 리플 지우기, `W` 재생 위치부터 뒷부분 리플 지우기. 컷 편집에서 가장 많이 씁니다.
- `Shift+Delete` 리플 삭제.
- `E` 고른 편집점을 재생 위치까지 늘이기 [2].

**트리밍 모드 [2].** 편집점을 두 번 누르면 트리밍 모드가 됩니다. 모니터에 앞 클립 끝과 뒤 클립 시작이 나란히 보이고, `,`/`.`로 한 프레임, `Shift+,`/`.`로 다섯 프레임씩 줄이고 늘입니다. 재생하면서 `J`/`K`/`L`로 트리밍합니다(동적 트리밍). 편집점마다 리플, 롤, 한쪽 자르기를 바꿉니다(`Ctrl+T`).

**제한 [1].** 원본보다 길게 늘이려 하면 끝에서 멈추고, 멈춘 이유("원본 끝")를 짧게 보여 줍니다. 잠긴 트랙과 동기 잠금을 지킵니다.

## 7. 키프레임, 마스크, 혼합

**기본 속성 [1].** 모든 영상 클립에 위치, 크기(가로세로 따로 [2]), 회전, 기준점, 불투명도, 자르기(위, 아래, 왼쪽, 오른쪽)가 있습니다. 소리 클립에 볼륨, 팬이 있습니다.

**키프레임 [1].**
- 효과 컨트롤 패널에서 속성 옆 시계를 누르면 키프레임이 켜집니다. 값을 바꾸면 재생 위치에 키프레임이 생깁니다.
- 이전·다음 키프레임 이동, 키프레임 추가·삭제, 여러 개 골라 옮기기·복사.
- 보간: 직선 [1], 부드럽게(베지어, 자동 베지어) [2], 멈춤(다음 키프레임까지 값 유지) [2], 시작·끝 천천히(Ease In/Out) [1].
- 그래프 보기 [2]: 값 그래프와 속도 그래프를 손잡이로 고칩니다.
- 위치 키프레임은 모니터에 움직임 경로로 그려지고, 경로 위 점을 끌어 고칩니다 [2].
- 타임라인 클립 위에도 고른 속성 하나의 키프레임 선을 보여 줍니다(예: 볼륨 고무줄) [1].

**마스크 [2].**
- 타원, 사각형, 펜으로 그린 자유 도형. 마스크마다 깃털(가장자리 흐림), 확장, 불투명도, 반전, 더하기·빼기·교차.
- 마스크 경로도 키프레임이 됩니다.
- 마스크 추적 [3]: 앞뒤 프레임을 따라가며 마스크를 옮깁니다(얼굴 가리기 등).

**혼합 모드 [2].** 보통, 곱하기, 스크린, 오버레이, 소프트 라이트, 더하기, 차이, 색상, 광도 등 흔한 15개. 셰이더 하나에서 고릅니다.

**조정 레이어 [2].** 내용 없는 클립입니다. 위 트랙에 두면 그 아래 모든 트랙에 효과와 색이 적용됩니다. 여러 클립에 같은 색을 넣을 때 씁니다.

**색 화면, 그라디언트, 검은 화면, 카운트다운 [1]/[2].** 프로젝트 패널의 "새 항목"으로 만듭니다.

## 8. 효과와 전환

**효과 적용 [1].** 효과 패널에서 클립으로 끌어다 놓거나, 클립을 고르고 두 번 누릅니다. 효과 컨트롤에서 순서를 바꾸고, 끄고, 지웁니다. 효과 묶음을 "효과 프리셋"으로 저장합니다 [2].

**영상 효과 목록.**

| 분류 | 효과 | 묶음 |
| --- | --- | --- |
| 변형 | 가로·세로 뒤집기, 자르기, 가장자리 늘리기(빈 곳 채우기) | [1] |
| 흐림 | 가우시안 흐림, 방향 흐림, 모자이크(얼굴 가리기) | [1] |
| 색 | 흑백, 색 입히기, 밝기·대비, 색 바꾸기 | [1] |
| 스타일 | 비네트, 필름 그레인, 선명하게 | [2] |
| 키잉 | 크로마키(초록·파랑 화면 빼기), 루마키 | [2] |
| 시간 | 잔상(에코), 정지 효과 | [2] |
| 왜곡 | 렌즈 왜곡 보정, 흔들림 보정(스태빌라이저) | [3] |
| 생성 | 격자, 그라디언트, 노이즈 | [2] |

모든 효과는 WGSL 셰이더 하나와 속성 표 하나로 만듭니다. 효과를 추가할 때 화면 코드를 고치지 않아도 되도록, 속성 표(이름, 종류, 범위, 기본값, 키프레임 가능 여부)에서 효과 컨트롤 UI를 만듭니다.

**전환 [1].**
- 영상: 디졸브, 검은 화면 거쳐 페이드, 흰 화면 거쳐 페이드, 밀기(4방향), 닦아내기, 확대 [2], 흐림 디졸브 [2].
- 소리: 같은 세기 크로스페이드(기본), 같은 크기 크로스페이드 [2].
- `Ctrl+D` 기본 영상 전환, `Ctrl+Shift+D` 기본 소리 전환, `Shift+D` 둘 다.
- 기본 길이는 1초(설정 가능). 전환 끝을 끌어 길이를 바꿉니다.
- 정렬: 편집점 가운데, 편집점에서 시작, 편집점에서 끝.
- 핸들이 모자라면(원본에 더 남은 프레임이 없으면) "프레임이 모자라 끝 프레임을 반복합니다"라고 알리고, 줄무늬로 표시합니다.

## 9. 속도와 시간

- **일정 속도 [1]:** `Ctrl+R`. 속도(%) 또는 길이로 정합니다. "뒤 클립 밀기(리플)"를 고를 수 있습니다. 소리 높낮이 유지(시간 늘이기 알고리즘)를 켭니다.
- **거꾸로 재생 [1].**
- **정지 프레임 [1]:** 재생 위치의 프레임으로 정지 화면을 만들어 넣습니다(`Shift+F` 등). 길이 2초가 기본입니다.
- **속도 램프 [2]:** 클립 안에서 속도를 키프레임으로 바꿉니다(빨라졌다 느려짐). 속도 키프레임 사이를 부드럽게 이을 수 있습니다.
- **프레임 보간 [2]:** 느리게 할 때 프레임을 반복(기본)하거나 앞뒤 프레임을 섞습니다. 움직임 추정으로 사이 프레임을 만드는 방식은 [3]입니다.
- 원본과 시퀀스 프레임 수가 다르면(24fps 원본, 30fps 시퀀스) 프레임 시간으로 가장 가까운 프레임을 고릅니다. 반올림 규칙을 하나로 정해서 미리보기와 내보내기가 같은 프레임을 씁니다.

## 10. 색 보정과 스코프

색은 클립 하나에 "색" 효과 하나로 들어가고, 순서는 효과 목록의 맨 끝이 기본입니다. 계산은 모두 선형 빛 공간에서 하고, 마지막에 Rec.709로 돌려 놓습니다.

**기본 보정 [1].**
- 입력 LUT(`.cube`, 로그 촬영 영상을 보통 색으로) [2]
- 화이트 밸런스: 색온도, 색조, 스포이드로 흰 곳 찍기 [1]
- 톤: 노출, 대비, 하이라이트, 섀도, 화이트, 블랙 [1]
- 채도, 바이브런스(덜 진한 색만 진하게) [1]
- 자동 [2]: 히스토그램으로 노출과 화이트 밸런스를 맞춥니다.

**창의 보정 [2].** 룩 LUT, 강도, 바랜 필름, 선명도, 섀도·하이라이트 색 입히기.

**커브 [2].** RGB 커브(전체, R, G, B)와 색상 대 채도, 색상 대 색상, 색상 대 밝기, 밝기 대 채도 커브.

**색 휠 [2].** 섀도, 미드톤, 하이라이트 휠 세 개와 각각의 밝기 슬라이더.

**HSL 보조 [2].** 화면에서 색을 찍어 그 색 범위만 고릅니다(색상, 채도, 밝기 범위와 부드러움). 고른 영역만 보기, 그 영역에 색온도·채도 등을 따로 적용합니다. 하늘만 파랗게, 피부색만 밝게 같은 작업입니다.

**비네트 [1].** 양, 중심, 둥근 정도, 부드러움.

**스코프 [2].** 파형(밝기, RGB), RGB 퍼레이드, 벡터스코프(피부색 선 표시), 히스토그램. GPU에서 프레임마다 계산하고, 재생 중에는 2프레임마다 갱신합니다. 방송용 범위(16~235) 넘침을 표시합니다.

**색 맞추기 [3].** 참고 프레임과 지금 프레임의 색 분포를 비교해 기본 보정 값을 제안합니다.

**HDR [3].** HDR10, HLG 입력을 SDR로 바꾸기와 HDR로 내보내기.

## 11. 텍스트와 그래픽

**텍스트 레이어 [1].**
- 텍스트 도구(`T`)로 모니터를 누르고 씁니다. 그래픽 클립이 타임라인에 생깁니다.
- 글꼴(설치된 시스템 글꼴과 앱에 넣은 한글 무료 글꼴 몇 개), 크기, 굵기, 기울임, 자간, 행간, 정렬.
- 채우기, 외곽선(여러 겹 [2]), 그림자, 배경 상자(여백, 둥근 모서리).
- 한 클립에 텍스트와 도형 레이어 여러 개 [2]. 레이어 순서, 정렬(가운데, 왼쪽 위 등), 배분.
- 한국어 입력기(IME)로 조합 중인 글자도 모니터에 바로 보입니다. 조합이 끝나기 전에는 편집 명령을 기록하지 않아서, 실행 취소가 글자 반쪽 단위로 쪼개지지 않습니다.

**도형 [2].** 사각형, 둥근 사각형, 타원, 선, 펜 도형.

**반응형 [2].** 배경 상자가 글 길이에 맞춰 늘어납니다. 레이어를 다른 레이어나 화면 가장자리에 고정합니다(글이 길어져도 안 겹침). 그래픽 클립의 시작·끝 부분을 "고정 구간"으로 두면 클립 길이를 늘여도 들어오고 나가는 애니메이션은 그대로입니다.

**스타일 [1].** 글자 스타일을 이름 붙여 저장하고, 다른 텍스트에 한 번에 씁니다. 스타일을 고치면 쓴 곳이 모두 바뀝니다 [2].

**움직임 프리셋 [1].** 나타나기(페이드, 아래에서 올라옴, 한 글자씩), 사라지기. 키프레임으로 만들어지므로 고칠 수 있습니다.

**롤과 크롤 [2].** 엔딩 크레딧처럼 위로 올라가기(롤), 뉴스 자막처럼 옆으로 흐르기(크롤).

**그래픽 템플릿 [2].** 그래픽 클립을 템플릿(`.ncgfx`)으로 저장하고, 바꿀 수 있는 항목(글, 색)을 정해 둡니다. 템플릿 목록에서 끌어다 쓰고 항목만 바꿉니다.

## 12. 소리

**클립 단위 [1].**
- 볼륨(dB), 팬, 페이드 인·아웃 손잡이(클립 모서리를 끌기).
- 고무줄: 클립 위 볼륨 선에 `Ctrl`+누르기로 키프레임을 찍어 구간별로 줄입니다.
- 오디오 게인 [1]: 클립의 기본 크기. "최대 피크를 -1dB로 맞추기"(노멀라이즈) [1].
- 채널 바꾸기 [2]: 왼쪽 마이크만 쓰기, 모노를 양쪽으로.
- 파형은 dB 눈금(소리가 작아도 보임)과 직선 눈금 중에서 고릅니다 [2].

**트랙 믹서 [2].** 트랙마다 볼륨 페이더, 팬, 음소거, 솔로, 피크 미터, 트랙 효과 칸 5개, 메인 출력 미터. 페이더 움직임을 재생 중에 기록해 키프레임으로 남깁니다(자동화) [3].

**소리 효과 [2].** EQ(파라메트릭 5밴드, 그래프), 컴프레서, 리미터, 디에서(ㅅ 소리 줄이기), 잡음 줄이기(잡음 구간 학습), 리버브, 피치 바꾸기, 딜레이. Web Audio 노드와 오디오 워클릿으로 만듭니다.

**소리 정리 패널 [2].**
- 클립을 대화, 음악, 효과, 배경으로 지정합니다.
- 대화: 음량 맞추기(목표 LUFS), 잡음 줄이기, 명료하게(EQ 프리셋).
- 음악: 대화가 나오는 동안 자동으로 줄이기(덕킹). 대화 클립 위치를 보고 음악 클립에 볼륨 키프레임을 만듭니다. 줄이는 양, 페이드 길이를 정합니다.
- 음악 길이 맞추기 [3]: 음악을 박자 경계에서 잘라 원하는 길이로 맞춥니다.

**음량 [1].** 내보내기 프리셋에 목표 음량을 둡니다(유튜브 -14 LUFS, 방송 -24 LUFS). 전체 시퀀스의 통합 음량과 실제 피크를 재서 보여 주고, "맞추기"를 누르면 메인 출력 게인을 정합니다.

**녹음 [2].** 보이스오버: 트랙의 마이크 버튼을 누르면 카운트다운 후 재생하면서 녹음하고, 그 트랙에 클립으로 넣습니다. 마이크 고르기, 입력 미터.

**동기 [1].** 미리보기는 소리 시계를 기준으로 영상을 맞춥니다. 소리와 영상 어긋남은 1프레임 이내가 기준입니다.

## 13. 자막

- **자막 트랙 [1]:** 영상 트랙 위에 따로 있는 트랙입니다. 자막 하나하나가 블록입니다.
- **자막 패널 [1]:** 시작, 끝, 글을 목록으로 보고 고칩니다. 줄을 누르면 그 위치로 갑니다. 찾기와 바꾸기 [2].
- **가져오기·내보내기 [1]:** SRT [1], WebVTT [2]. 글자 인코딩(UTF-8, CP949)을 자동으로 알아냅니다.
- **스타일 [1]:** 글꼴, 크기, 색, 배경, 위치(아래, 위). 줄 길이 제한(예: 한 줄 18자)을 넘으면 표시합니다 [2].
- **내보낼 때 [1]:** 영상에 그려 넣기(번인) 또는 따로 SRT 파일. 둘 다 고를 수 있습니다.
- **여러 언어 [2]:** 자막 트랙을 언어마다 둡니다.
- **음성 인식 자막 [3]:** 대화 클립에서 자동으로 자막을 만듭니다. Mind 앱의 로컬 모델(Whisper 계열)을 쓸 계획이라 Mind 이후입니다.

## 14. 마커

- `M` 마커 넣기 [1]. 클립을 고른 상태면 클립 마커, 아니면 시퀀스 마커.
- 이름, 메모, 색, 길이(범위 마커) [1].
- 종류: 메모 [1], 챕터 [1], 구간 [2].
- 마커 패널 [2]: 목록, 색으로 거르기, 누르면 이동.
- 마커에 붙기 [1].
- 유튜브 챕터 내보내기 [1]: 챕터 마커를 `00:00 제목` 줄 목록으로 복사합니다(설명란에 붙여 넣기 용).

## 15. 내보내기

**설정 [1].**
- 프리셋: 유튜브 1080p, 유튜브 4K, 쇼츠·릴스, 720p 가볍게, 소리만(M4A), 높은 화질 보관용 [2].
- 형식: MP4(H.264, HEVC [하드웨어만]) [1], WebM(VP9, 소프트웨어) [2], MOV [3], GIF [2], PNG 이미지 시퀀스 [2].
- 해상도, 프레임 수, 비트레이트 방식(일정, 가변 1회, 가변 2회 [2]), 목표·최대 비트레이트, 키프레임 간격.
- 소리: AAC 128~320kbps, Opus [2], 48kHz.
- 범위: 전체, In~Out, 작업 영역 [2].
- 예상 크기와 이 PC에서 걸릴 시간(추정)을 보여 줍니다.
- 메타데이터: 제목, 챕터(MP4 챕터 상자) [2].

**대기열 [2].** 내보내기를 대기열에 넣고 편집을 계속합니다. 대기열은 한 번에 하나씩 처리합니다. 편집 중인 미리보기와 GPU를 나눠 쓰므로 미리보기가 느려질 수 있다고 알립니다.

**스마트 렌더 [2].** 아무것도 바뀌지 않은 구간(자르기만 한 클립)은 압축을 다시 하지 않고 원본 데이터를 그대로 복사합니다. 코덱, 해상도, 프레임 수가 같을 때만 됩니다. 컷 편집만 한 긴 영상이 훨씬 빨리 나옵니다.

**확인 [1].** 다 쓴 뒤 파일을 다시 열어 길이, 프레임 수, 첫·끝 프레임, 소리 길이를 확인합니다. 어긋나면 알립니다.

**지금 프레임 저장 [1].** `Ctrl+Shift+E`로 프로그램 모니터 프레임을 PNG로 저장합니다(썸네일용).

**프로젝트 교환 [3].** EDL, FCPXML, OpenTimelineIO로 내보내고 가져오기.

## 16. 성능: 재생, 프록시, 렌더 미리보기

- **재생 화질 [1]:** 전체, 1/2, 1/4. 멈췄을 때는 전체 화질로 다시 그립니다.
- **프레임 떨굼 표시 [1]:** 실시간 재생을 못 따라가면 떨어진 프레임 수를 모니터 구석에 보여 줍니다.
- **프록시 [1]:** 클립을 고르고 "프록시 만들기"를 하면 뒤에서 720p H.264(키프레임 간격 짧게) 사본을 만듭니다. 모니터의 "프록시 켜기" 버튼으로 바꿉니다. 내보내기는 항상 원본을 씁니다. 4K, HEVC, 키프레임 간격이 긴 휴대폰 영상은 가져올 때 프록시를 권합니다.
- **렌더 미리보기 [2]:** 타임라인 위 띠가 구간 상태를 색으로 보여 줍니다. 초록은 렌더 파일이 있음, 노랑은 실시간이 될 것 같음, 빨강은 실시간이 어려움입니다. `Enter`로 In~Out 구간을 미리 렌더합니다. 그 구간을 고치면 렌더 파일이 버려집니다.
- **캐시 [1]:** 썸네일, 파형, 프록시, 렌더 파일을 공통 캐시에 둡니다. 설정에서 크기 한도와 지우기를 둡니다. 오래 안 쓴 것부터 지웁니다.
- **프레임 캐시 [1]:** 재생 위치 앞쪽 프레임을 미리 풉니다. GPU 메모리 한도(설정, 기본 VRAM의 50%)를 넘으면 먼 것부터 버립니다.
- **뒤에서 하는 일 [1]:** 썸네일, 파형, 프록시는 일 대기열 하나에서 처리하고, 재생 중에는 잠깐 멈춥니다.

## 17. 기록, 자동 저장, 복구

- **실행 취소 [1]:** 끝없이(메모리 한도 안에서). 모든 편집은 명령 하나로 기록됩니다. 슬라이더를 끄는 동안의 변화는 손을 뗄 때 명령 하나로 묶습니다.
- **기록 패널 [2]:** 명령 목록에서 원하는 지점을 누르면 그때로 돌아갑니다.
- **자동 저장 [1]:** 편집이 멈추고 2초 뒤에 저장합니다. 따로 5분마다 `자동 저장/` 폴더에 사본을 남기고 최근 20개를 유지합니다.
- **복구 [1]:** 앱이 비정상으로 끝나면 다음 시작 때 마지막 자동 저장을 열지 묻습니다.
- **버전 [2]:** "지금 버전 저장"으로 이름 붙인 스냅숏을 남기고 비교하거나 되돌립니다.

## 19. 데이터 모델

시간은 모두 정수 틱입니다. 1초 = 254,016,000,000틱(여러 영상 편집 앱이 쓰는 값과 같은 방식으로, 23.976, 24, 25, 29.97, 30, 50, 59.94, 60fps와 44.1k, 48kHz 표본이 모두 정수로 떨어짐). JavaScript에서는 `BigInt`가 아니라 안전한 정수 범위 안의 `Number`로 다룹니다(2^53 / 254,016,000,000 ≈ 9.8시간이라, 10시간이 넘는 시퀀스는 막습니다. 넘는 경우가 생기면 BigInt로 바꿉니다).

```jsonc
{
  "format": "ncut", "version": 1,
  "media": [{ "id": "m1", "path": "D:/영상/여행_01.mp4", "kind": "video", "duration": 5080320000000,
              "video": { "w": 1920, "h": 1080, "fps": [30, 1], "codec": "avc1.640028", "vfr": false },
              "audio": { "rate": 48000, "channels": 2 }, "interpret": null, "proxy": "cache:ab12…" }],
  "bins": [{ "id": "b1", "name": "촬영본", "items": ["m1"] }],
  "sequences": [{
    "id": "s1", "name": "브이로그", "w": 1920, "h": 1080, "fps": [30, 1], "rate": 48000,
    "tracks": [{ "id": "V1", "kind": "video", "locked": false, "visible": true, "syncLock": true },
               { "id": "A1", "kind": "audio", "mute": false, "solo": false, "volume": 0, "pan": 0, "effects": [] }],
    "clips": [{ "id": "c1", "track": "V1", "source": { "media": "m1" },
                "start": 0, "in": 254016000000, "out": 2540160000000,
                "speed": 1, "reverse": false, "link": "L1", "group": null, "enabled": true, "label": "blue",
                "props": { "position": [0, 0], "scale": [100, 100], "rotation": 0, "anchor": [0, 0], "opacity": 100 },
                "keyframes": { "opacity": [{ "t": 0, "v": 0, "ease": "out" }, { "t": 7620480000, "v": 100 }] },
                "effects": [{ "id": "e1", "type": "color.basic", "on": true, "params": { "exposure": 0.3 } }],
                "masks": [] }],
    "transitions": [{ "id": "t1", "track": "V1", "at": 2540160000000, "type": "dissolve", "duration": 254016000000, "align": "center" }],
    "markers": [{ "t": 0, "name": "인트로", "kind": "chapter", "color": "green" }],
    "captions": [{ "track": "CC1", "lang": "ko", "items": [{ "start": 0, "end": 762048000000, "text": "안녕하세요" }] }]
  }]
}
```

- 클립의 `start`는 타임라인 위치, `in`/`out`은 원본 안의 구간입니다. 타임라인 길이는 `(out - in) / speed`입니다.
- 키프레임 시간 `t`는 클립 시작 기준입니다. 클립을 옮겨도 키프레임이 따라옵니다.
- 효과는 `type`과 `params`만 저장합니다. 효과의 속성 표가 기본값을 줍니다. 그래서 효과에 새 속성을 더해도 옛 프로젝트가 열립니다.
- 편집 명령은 이 JSON에 대한 작은 변경 목록(바꾼 경로, 옛 값, 새 값)으로 기록합니다. 실행 취소는 그 목록을 거꾸로 적용합니다.
- 파일을 열 때 `version`을 보고 옛 형식을 새 형식으로 바꿉니다. 바꾸기 전 파일은 `.bak`으로 남깁니다.

## 21. 테스트

영역마다 테스트가 직접 만든 시험 미디어를 씁니다(프레임 번호가 그려진 영상, 1초마다 삐 소리, 색 막대). 저작권 있는 영상은 쓰지 않습니다.

| 영역 | 검사 |
| --- | --- |
| 편집 명령 | 명령마다 "하고 되돌리면 처음과 같음", "두 번 해도 깨지지 않음". 무작위 편집 1,000개를 하고 모두 되돌리면 처음 JSON과 같은지(무작위 테스트). |
| 리플·동기 잠금 | 리플 삭제 후 동기 잠금된 소리와 자막이 같은 양만큼 밀렸는지 |
| 프레임 정확도 | 30fps 시퀀스, 24fps·60fps·29.97fps·가변 프레임 원본에서 시간 t의 프레임 번호가 계산값과 같은지 |
| 미리보기와 내보내기 | 같은 시퀀스의 프레임을 미리보기와 내보낸 파일에서 뽑아 비교(PSNR 35dB 이상) |
| 소리 | 삐 소리 시작 위치가 화면 깜빡임과 1프레임 이내, 내보낸 파일 음량이 목표 LUFS ±1 |
| 효과 | 효과마다 기준 그림과 비교(작은 오차 허용). 속성 표에서 UI가 만들어지는지 |
| 색 | 색 막대에 보정을 넣고 픽셀 값이 수식 결과와 같은지. 스코프 값이 CPU 계산과 같은지 |
| 텍스트 | 한글 IME 조합, 줄바꿈, 배경 상자 크기 |
| 자막 | SRT 가져오기·내보내기 왕복이 같은지, CP949 파일 |
| 오프라인 미디어 | 파일을 옮긴 뒤 열기, 폴더로 다시 연결 |
| 복구 | 편집 중 프로세스를 강제로 끝내고 다시 열면 마지막 자동 저장이 열리는지 |
| 화면 | 실제 마우스 이벤트로 끌어 놓기, 끝 자르기, 도구 바꾸기, 단축키, 스크린샷 |
| 메모리 | 10분 재생 후 열린 `VideoFrame` 수가 0으로 돌아오는지, GPU 메모리가 늘지 않는지 |
